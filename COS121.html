1 - What is Problem Solving?

A problem is a situation requiring a solution without an immediate answer. Problem solving is the process of identifying, analyzing, and solving a problem using logical and systematic steps. It often involves a series of simple steps rather than one giant leap.

Key Idea: Problem solving = Identify, Analyze, Solve with logical steps.

2 - The Four Steps of Problem Solving

StepDescription
1. Analyze the problemUnderstand the problem's nature, requirements, and constraints.
2. Design the solutionPlan a step-by-step method (algorithm) before coding.
3. Implement the solutionExecute the plan (write code, build system, perform actions).
4. Test and EvaluateCheck if the solution works correctly and meets requirements.

3 - Problem Identification

Before solving, you must recognise the problem:

  1. Recognize the need - realise a problem exists.
  2. Define the problem clearly - state it precisely.
  3. Identify the inputs and outputs - what goes in and what comes out.
  4. Identify constraints/limitations - note restrictions.

4 - Key Elements of Compiling (Problem Solving Context)

ElementRole
InputData entered into the system
ProcessingOperations performed on the data
OutputResult of the processing
StorageHolds data or results during/after processing

Data processing = transforming raw data into human-readable form. Automation = using technology to perform a task with little or no human intervention. Algorithm = step-by-step method to solve a problem.

5 - Non-Linear (Routine) Problems

These problems follow a known formula or procedure. They are predictable, easy to solve, require little creativity, and have a known method with low complexity.

Examples: Calculate area of a rectangle, convert Celsius to Fahrenheit, find average of three numbers.

6 - None Routine (Non-Routine) Problems

These problems have no direct solution. They require creativity and deep thinking. Characteristics: always complex, require reasoning, multiple possible solutions, no fixed procedures.

Examples: Build an AI system, design a new encryption protocol, create a business plan.

8 - Pattern Recognition

Identify similarities within a problem and reuse known solutions. Patterns must be well defined, structured, easy to analyze - no ambiguity.

Habit to develop: Break down problems into small parts and solve them logically (decomposition).

9 - Five Pattern Steps

  1. Break down the problem
  2. Identify the pattern
  3. Identify the relationship
  4. Formulate the solution
  5. Evaluate the result

Algorithm Basics

An algorithm is a finite sequence of well-defined, unambiguous steps that produce a correct output for a given input. Key properties: Finiteness (must terminate), Definiteness (clear steps), Input/Output (well-defined), Effectiveness (feasible operations).

Pseudocode - informal, structured description of an algorithm. Flowcharts - graphical representation using symbols: oval (start/end), parallelogram (I/O), diamond (decision), rectangle (process), circle (connector).

Complexity Analysis

TypeMeaning
Time ComplexityHow execution time grows with input size.
Space ComplexityHow memory usage grows with input size.
Big-O NotationDescribes worst-case growth (e.g., O(n), O(log n), O(n^2)).
Best / Worst / Average CasePerformance under optimal, worst, and typical inputs.

Examples: Linear search O(n), Binary search O(log n), Bubble sort O(n^2), Merge sort O(n log n), Quick sort average O(n log n).

Problem-Solving Strategies

  • Decomposition - break into sub-problems.
  • Abstraction - hide irrelevant details.
  • Brute Force - try all possibilities.
  • Heuristics - approximate / rule-of-thumb.
  • Divide & Conquer - split, solve, combine.
  • Greedy - make best immediate choice.
  • Dynamic Programming - store solutions to sub-problems to avoid repetition.
  • Recursion - function calls itself; needs a base case.
  • Backtracking - systematic trial and error for constraints.
  • Branch & Bound - prune search space for optimisation.
